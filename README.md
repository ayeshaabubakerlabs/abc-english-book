# 📖 ABC English Book

### A Kindergarten Alphabet Learning Resource

**Created and Designed by Ayesha Abubaker**

---

## 📌 Project Overview

**ABC English Book** is a 29-page kindergarten English alphabet learning resource created and designed by **Ayesha Abubaker** using **Microsoft Word**.

The project was developed as a personal portfolio piece to demonstrate practical skills in:

* 📄 Microsoft Word document design
* 📐 Page layout and composition
* 🔠 Typography and visual hierarchy
* 🧒 Educational content presentation
* 📑 Consistent multi-page formatting
* 👁️ Visual organization
* 🤖 AI-assisted creative workflows

The completed book includes a cover page, individual **A–Z alphabet learning pages**, an **A–Z visual reference page**, and a closing/creator-credit page.

---

## 🎯 Project Objectives

The main objectives of this project were to:

* 🧸 Create an engaging alphabet-learning resource for kindergarten learners.
* 📚 Design a complete multi-page educational document using Microsoft Word.
* ✨ Apply consistent typography, spacing, alignment, and visual hierarchy.
* 🧩 Organize educational content in a clear and child-friendly format.
* 🔍 Demonstrate attention to detail in document composition and page formatting.
* 💼 Produce a polished digital artifact suitable for a professional portfolio.

## 🖼️ Visual Content & AI-Assisted Workflow

The visual content in this project was created through an **AI-assisted workflow**.

Some illustration concepts were informed by visual ideas or references encountered online. The final visuals used in the book were not simply presented as direct website downloads; **Google Gemini was used to generate and/or refine illustrations** before they were incorporated into the Microsoft Word document.

The document design and composition remain the work of **Ayesha Abubaker**, including:

* Page structure
* Typography
* Image placement
* Formatting
* Visual organization
* Overall presentation

This project is therefore presented as an **AI-assisted visual design and document-design project**, rather than as a claim that every illustration was independently hand-drawn or photographed by the creator.
